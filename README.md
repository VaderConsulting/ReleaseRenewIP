# ReleaseRenewIP

Freelance VB6 DHCP Test utility (`ReleaseRenew.exe`) that releases and renews DHCP leases (WMI), shows release/renew status icons, and appends results to `DHCP.log`. Open `ReleaseRenew.vbp` in the VB6 IDE.
